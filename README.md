# 特种作业 / 二装审批 Mini App 前端 Demo

这是独立前端 demo，专门用于演示特种作业和二装审批的小程序端流程。

## 试用

当前静态服务地址：

```text
http://localhost:4301
```

也可以直接打开 `index.html`。

## 覆盖流程

- 选择作业类型：二装入场、幕墙清洗、动土、动火
- 填写申请信息
- 勾选风险项：动火、动土、临时用电/断电、高空、夜间施工
- 联动材料清单
- 提交申请
- 查看审批进度
- 模拟补件 / 押金凭证
- 模拟推进节点
- 查看结果单 / 放行许可

## 边界

- 只改 `D:\tfjssaas\new-mvp-frontend-demo`。
- 不改 `D:\tfjssaas\Develop`。
- 不推进原项目生命周期状态。
- 当前不接真实后端，所有交互为本地前端模拟。
